Put every temporary file (logs, copies, build output, screenshots, browser --user-data-dir, mktemp) in /tmp/<card number>/. The board set the TMPDIR and KANBAN_TMP environment variables to it when it opened you; if they are not set, create it yourself from this card's number. Use your own card's number and no other name (not the reviewed card's or any other card's number, and no invented names like kbn0074-after or xxx-review-random).
