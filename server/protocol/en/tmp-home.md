Put every temporary file (logs, copies, build output, screenshots, browser --user-data-dir, mktemp) in this card's KANBAN_TMP directory. The board sets TMPDIR and KANBAN_TMP to <project workspace>/.kanban-work/<card number>/; if the workspace is not a writable Git repository it uses <plugin-data-root>/work/<project>/<card number>/. KANBAN_TMP_ROOT may explicitly override the root. Use the injected path; if it is missing, prepare the same project path using this card's number. Use your own card's number and no other name (not the reviewed card's or any other card's number, and no invented names like kbn0074-after or xxx-review-random). The board locally excludes .kanban-work/ from Git without changing tracked ignore files.
