Board work rules (executor):
1. Read this card with kanban_show first.
2. Work only in the card's working directory. Commit after every step.
3. Finish with kanban_complete. The handoff must include files, verification and risks. For repositories without CI, run tests and the build locally before a merge and record the results in the handoff. Waiting for another PR to merge is not a block: when the deliverable is ready and you are waiting for a PR merge or another card, complete as usual and say what you are waiting for in the optional handoff.waitingOn (for example "merge of PR <url>"). The card then shows "Waiting on external: …" and the <leader> checks it at acceptance. On a repository with no CI, run the tests and the build locally before you complete, and write the commands and results into verification. When waiting for CI, complete the card and describe it in handoff.waitingOn.
4. Use kanban_block with kind=needs_human only when a person is truly needed (permissions, a user decision, and so on). kind still accepts dependency, needs_human, capability, quota, rate_limit, transient, scheduled; an executor reporting dependency for waiting on a PR or another card is refused: "That is not a block. Complete the card and say in the handoff what you are waiting for."
   For wall-clock waits, use kanban_block with kind=scheduled and until: a future ISO timestamp with an explicit timezone offset (Z or +/-HH:MM), at most 7 days away. Do not use transient for timed waits. The board resumes once at the deadline, including after a restart; the <leader> may unblock early. For longer waits ask the <leader> to use wait-user.

6. Where the tools allow, hand separable searching, reading, testing and checking to sub-agents in parallel, then combine the results. Make code changes yourself so nobody overwrites anybody. {subagentWait}
7. If you need a PR, you may create a branch in this card's directory, but do not open another worktree. When merging a PR, do not check out the PR head branch as the current branch in this card's temporary worktree. Push from a separate local branch or ref, or run gh pr merge without checking out the head. If you switch to another PR's branch, switch back to this card's branch before gh pr merge; otherwise Paseo archives the whole directory after the merge and takes you with it.
A merge card may depend on a PR card; the board recognises this and will not deadlock. Use role=batch and name the same-repository PR number or full link in the title or brief.
8. {tmpHome} Keep them inside that locally ignored directory; the board deletes this card’s KANBAN_TMP directory 24 hours after the card ends, so paste any evidence worth keeping into the handoff or a card comment. git status --short must be empty before you complete (untracked files count too); clean up or move things out first.
