# 安全策略

不要在公开 issue、PR、讨论中披露凭证、涉及私有数据的利用细节、真实库、完整 host 配置或敏感日志。

计划使用本仓库 GitHub private vulnerability reporting：Security 页有 Report a vulnerability 时从那里私下报告。所有者须在公开发布前启用；本文不声称已启用。按钮不可用时不要公开敏感细节，等待私下渠道提供。不公布邮箱，不保证响应时间。

私下报告列受影响插件/伴随版本、OS/Paseo、安装来源、影响、最小演示复现，也要脱敏凭证与个人标识。评估修复后和所有者协调公开披露。

项目 experimental；安全修复和支持版本记 CHANGELOG Security/Notes，无长期支持或修复时限承诺，tag 不证明稳定。见 [RELEASE](RELEASE.md)。
